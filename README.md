# 🌟 HTML Personal Profile Website

A multi-page personal portfolio website built using pure **HTML5** as part of the **TechMood Front-End Bootcamp**. This project focuses on structuring semantic web pages, text content, lists, data tables, and interactive HTML forms.

## 🚀 Features & Pages
- **Home Page (`index.html`):** Displays the main profile introduction, bio, skills list, skills tracking table, and a contact form.
- **About Page (`about.html`):** Dedicated page providing more background details.
- **Contact Page (`contact.html`):** Dedicated page for user communication.
- **Structured Assets:** Organized folder structure keeping profile images separate.
